Firebase 設定向導
⚠️ 請先完成以下步驟，再將此 HTML 檔案部署或用瀏覽器開啟使用
步驟一｜建立 Firebase 專案
  1. 前往 console.firebase.google.com
  2. 點擊「新增專案」，輸入專案名稱（例：kaihat-club）
  3. 可關閉 Google Analytics，點擊「建立專案」
步驟二｜啟用 Authentication
  1. 左側選單 → Authentication → 開始使用
  2. Sign-in method → 啟用「電子郵件/密碼」
步驟三｜建立 Firestore 資料庫
  1. 左側選單 → Firestore Database → 建立資料庫
  2. 選擇「以測試模式開始」→ 選擇位置（建議 asia-east1）
步驟四｜取得設定並填入程式碼
  1. 專案設定（齒輪圖示）→ 你的應用程式 → 新增 Web 應用程式
  2. 複製 firebaseConfig 物件
  3. 用記事本開啟此 HTML 檔案
  4. 搜尋 YOUR_API_KEY，替換整個 FIREBASE_CONFIG 物件
步驟五｜設定 Firestore 安全規則（正式使用）
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/data/{document} {
      allow read, write: if request.auth != null
                         && request.auth.uid == userId;
    }
  }
}
